# =====================================================================
#   regras.txt - Comandos instantâneos (sem IA)
# =====================================================================
# FORMATO DE CADA LINHA:   gatilho 1, gatilho 2, gatilho 3 = ação
#
# - Linhas começando com # são comentários.
# - Maiúsculas e acentos não importam.
# - Um gatilho com ! na frente (ex: !play) só vale quando você falar
#   EXATAMENTE aquilo e mais nada. Use em palavras curtas, pra elas não
#   dispararem no meio de uma conversa. O que não casar com nenhuma regra
#   vai para a IA (mais lento, mas entende frases livres).
# - {n} no gatilho = qualquer número de 0 a 100 que você falar. Na ação,
#   {n} vira esse número. Ex: "volume em {n} = definir_volume({n})".
#
# AÇÕES PRONTAS PARA USAR (depois do sinal de =):
#   abrir_app('youtube')      -> abre o app ou site (ou foca, se já estiver aberto).
#                                Os nomes vêm do "apps_e_sites" do config.json.
#   no_navegador('ctrl+w')    -> traz o navegador pra frente e manda o atalho. O
#                                navegador vem do "navegador_padrao" do config.json
#                                (auto, brave, chrome, edge ou opera). Se ele não
#                                estiver aberto ou não vier pra frente, o atalho
#                                NÃO é enviado. Aceita um nome fixo:
#                                no_navegador('ctrl+w', 'chrome'). (no_navegador(...)
#                                ainda funciona: é o mesmo que no_navegador.)
#   focar_navegador()         -> só traz o navegador pra frente (True/False)
#   minimizar_navegador()     -> minimiza o navegador (aceita nome: ('brave'))
#   maximizar_navegador()     -> maximiza o navegador (aceita nome: ('brave'))
#   minimizar_app('Discord')  -> minimiza as janelas com esse título
#   maximizar_app('Discord')  -> maximiza as janelas com esse título
#   definir_volume(35)        -> volume exato de 0 a 100
#   confirmar('Pergunta?', "código")  -> ela pergunta e só executa se você disser "sim"
#   pyautogui.press('tecla') / pyautogui.hotkey('ctrl', 'w')  -> teclas diretas
# =====================================================================
