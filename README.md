O **GargaAI v1.0** é a primeira versão estável de um assistente de voz local para Windows, capaz de pausar vídeos, abrir sites, controlar abas de navegadores e executar atalhos do sistema.

### 🚀 Como usar
1. Baixe o projeto (Code → Download ZIP)
2. Extraia a pasta
3. Entre na pasta `gargaIA`
4. Dê dois cliques em **`iniciar.bat`**

Na primeira vez ele vai instalar o necessário e baixar o modelo de IA (pode demorar).  
Nas próximas vezes abre mais rápido.

## 🇺🇸 English

### 💡 About the Project
Hello everyone! I **don't know anything about programming**. I simply had this idea and used AI tools to help me build and structure the code. To be completely honest, I don't know if the code is fully optimized or great, because I have never done anything like this before in my life!

**GargaAI v1.0** is the first stable version of a local Windows voice assistant capable of pausing videos, opening websites, managing browser tabs, and triggering system shortcuts.

### 🚀 How to use
1. Download the project (Code → Download ZIP)
2. Extract the folder
3. Open the `gargaIA` folder
4. Double-click **`iniciar.bat`**

On the first run it will install what is needed and download the AI model (it may take a while).  
After that it starts faster.
